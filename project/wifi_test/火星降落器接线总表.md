# 火星降落器接线总表（持续维护）

> **用途**：本文件是火星降落器实际电气接线的唯一汇总入口。每次改变实体接线、端口、GPIO 分配、供电或固件所依赖的连接时，必须同步更新本文件，并在“变更记录”中增加一行。
>
> **安全原则**：所有未在“已确认”列明确标注的项目，均不得当作已完成实体接线。推杆运动路径目前保持安全锁定，不能因为表中存在历史引脚方案而解锁。

## 2. 系统连接概览

```text
OV5647 ── MIPI-CSI + SCCB/I²C + XCLK ──> ESP32-P4 ── SDIO(4-bit) ──> ESP32-C6 ── Wi-Fi ──> PC 控制台
                                               │
BNO085 ── UART-RVC（单向 TX→RX）───────────────┤
                                               │ USB-A（USB OTG Host）
                                               v
                             Arduino Mega 2560（USB-B / CH340）
                               └── HC-SR04（距离标尺校正；不用于单腿闭环）

Arduino Mega 2560 ── I²C ──> TCA9548A ── CH0..CH3 ──> 4×VL53L1X（推杆长度/行程传感器）
Arduino Mega 2560 ── 数字输出 ──> 4 路推杆驱动器 IN1 / IN2 / EN
```

## 13. 每次更新的最小核对清单

1. 修改任何实体线缆前，先拍照并写下端点丝印；改线后将旧状态移入“历史/废弃”而不是直接删除。
2. 对 P4 GPIO：核对 `wifi_test/main/` 和 `sdkconfig`，确认没有占用冲突；特别检查 GPIO14（C6 SDIO D0）。
3. 对 Mega：核对实际烧录的 `.ino` 文件，而不是只看历史测试草稿。
4. 对 5V 设备：确认没有把 5V 信号接入 P4 的 3.3V GPIO；HC-SR04 ECHO 当前只能接 Mega D50。
5. 对推杆：确认动力电源、公共地、急停、限位、驱动器 EN 极性；未完成前维持软件安全锁。
6. 做不超过 3 秒的短测并保存串口日志；将测试时间、结果和异常添加到下表。
7. 同步更新本文件的“状态”“备注”和“变更记录”。
